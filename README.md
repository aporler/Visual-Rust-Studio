# Visual Rust Studio (VRS)

*[English](#english) · [Français](#français)*

---

## English

**The simplicity of visual development, the power of Rust.**

Visual Rust Studio is a free and open-source integrated development
environment, written in Rust and dedicated to Rust. It brings back the
Visual Studio + VB.NET + Windows Forms experience:

1. create a "Graphical Application" project;
2. get a `Form1` window;
3. drag buttons, labels and text boxes onto it;
4. edit their properties;
5. double-click a button to write its code;
6. build and run.

**Rust stays Rust.** The applications you create are ordinary Cargo projects
written in readable Rust: they build with `cargo build` and open in any editor
(VS Code, RustRover…), even without VRS.

> Status: development preview (0.1). See [docs/STATUS.md](docs/STATUS.md) for
> what actually works and what remains to be done.

### Building and running VRS

Requirements: Rust 1.95 or newer ([rustup.rs](https://rustup.rs)).

```sh
cargo run --release -p vrs-app        # launches the IDE (binary "vrs")
cargo test --workspace                # unit tests and UI tests
cargo test -p vrs-project --test standalone -- --ignored   # a generated project builds without VRS
```

On Linux, the usual X11/Wayland development libraries are required
(`libxkbcommon-dev`, `libwayland-dev`, `libx11-dev`, and `libgtk-3-dev` for
file dialogs).

### Languages

The interface is available in French (Canada, France), English (United States,
Canada) and Spanish (Spain). Change the language in
**Tools → Settings → Language**: it applies immediately, with no restart.

Translations are [Fluent](https://projectfluent.org/) files in
`locales/<code>/*.ftl`. To add a language without recompiling, put your files
in the configuration folder (shown in the settings), under `locales/<code>/`.
To check a translation:

```sh
cargo run -p vrs-i18n --bin vrs-i18n-check -- path/to/locales
```

### Examples

14 example projects, from beginner to advanced, are in [exemples/](exemples/)
(English and French) and in **File → Examples…** in the IDE.

## Français

**La simplicité du développement visuel, la puissance de Rust.**

Visual Rust Studio est un environnement de développement intégré libre, écrit
en Rust et consacré à Rust. Il reprend l'expérience de Visual Studio avec
VB.NET et Windows Forms :

1. créer un projet « Application graphique » ;
2. obtenir une fenêtre `Form1` ;
3. y glisser des boutons, des étiquettes et des zones de texte ;
4. modifier leurs propriétés ;
5. double-cliquer sur un bouton pour écrire son code ;
6. compiler et exécuter.

**Rust reste Rust.** Les applications produites sont des projets Cargo
ordinaires, en Rust lisible : elles compilent avec `cargo build` et s'ouvrent
dans n'importe quel éditeur (VS Code, RustRover…), même sans VRS.

> État : préversion de développement (0.1). Voir [docs/STATUS.md](docs/STATUS.md)
> pour ce qui fonctionne réellement et ce qui reste à faire.

### Compiler et lancer VRS

Prérequis : Rust 1.95 ou plus récent ([rustup.rs](https://rustup.rs)).

```sh
cargo run --release -p vrs-app        # lance l'IDE (binaire « vrs »)
cargo test --workspace                # tests unitaires et tests d'interface
cargo test -p vrs-project --test standalone -- --ignored   # un projet généré compile sans VRS
```

Sous Linux, les bibliothèques de développement X11/Wayland usuelles sont
nécessaires (`libxkbcommon-dev`, `libwayland-dev`, `libx11-dev`, et
`libgtk-3-dev` pour les dialogues de fichiers).

### Langues

L'interface est disponible en français (Canada, France), en anglais
(États-Unis, Canada) et en espagnol (Espagne). Le changement de langue se fait
dans **Outils → Paramètres → Langue** et s'applique immédiatement, sans
redémarrage.

Les traductions sont des fichiers [Fluent](https://projectfluent.org/) dans
`locales/<code>/*.ftl`. Pour ajouter une langue sans recompiler, déposez vos
fichiers dans le dossier de configuration (affiché dans les paramètres), sous
`locales/<code>/`. Pour vérifier une traduction :

```sh
cargo run -p vrs-i18n --bin vrs-i18n-check -- chemin/vers/locales
```
